# Triage Labels

Skill'ler beş kanonik triage rolüyle konuşur. Bu dosya o rolleri bu repo'nun issue tracker'ındaki gerçek label string'lerine eşler.

| mattpocock/skills'teki label | Bizim tracker'daki label | Anlamı                                        |
| ---------------------------- | ------------------------ | --------------------------------------------- |
| `needs-triage`               | `needs-triage`           | Değerlendirilmeyi bekliyor                    |
| `needs-info`                 | `needs-info`             | Daha fazla bilgi bekleniyor                   |
| `ready-for-agent`            | `ready-for-agent`        | Tam tanımlı, ajan tek başına yapabilir        |
| `ready-for-human`            | `ready-for-human`        | İnsan eliyle yapılması gerekiyor              |
| `wontfix`                    | `wontfix`                | Yapılmayacak                                  |

Bir skill bir rolden bahsettiğinde (örn. "AFK-ready triage label'ını uygula"), bu tablodaki karşılık gelen label string'ini kullan.
